# Comerciar

Plataforma multi-comercio para gestionar ventas digitales, inventario, clientes y operaciones. El primer perfil de uso es belleza y cuidado personal en Argentina.

## Alcance inicial

- Pedidos manuales de WhatsApp e Instagram.
- Productos con variantes configurables, lotes y vencimientos opcionales.
- Reservas de stock con vencimiento, pagos manuales o parciales y envíos manuales.
- Múltiples comercios aislados, roles y auditoría.

La estructura es un monorepo con `apps/web`, `apps/api`, `packages/database` y `packages/contracts`.

## Estado

El proyecto está en la fase de base técnica y prototipo funcional. Consultá `docs/` para arquitectura y seguridad.
