# Panel de gestión — frontend

Prototipo responsive de la aplicación web para comercios de belleza y cuidado personal. Usa datos de demostración; no requiere backend.

## Requisitos

- Node.js 20.9 o superior
- npm 10 o superior

## Ejecutar en desarrollo

Desde esta carpeta:

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Comprobar una compilación de producción

```bash
npm run build
npm run start
```

La interfaz se encuentra principalmente en `src/app/page.tsx` y sus estilos en `src/app/globals.css`.
